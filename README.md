# BareHTTP

A minimal HTTP server implemented from scratch in TypeScript
using Node.js TCP sockets.

## Motivation

Built while following the Build Your Own Web Server guide
to understand TCP, HTTP parsing, buffering, and request handling.

## Current Features

- TCP connection handling
- Dynamic buffer implementation
- HTTP request parsing
- HTTP response encoding
- Content-Length request body handling
- Basic `/echo` endpoint

## Tech Stack

- TypeScript
- Node.js
- TCP sockets

## Running Locally

pnpm install
pnpm dev
